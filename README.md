# LearnInfra website

A classic, responsive static website concept for LearnInfra, built using HTML, CSS and vanilla JavaScript.

## Features
- Responsive navigation and premium corporate visual design
- Searchable, category-filtered course catalog
- Interactive curriculum dialogs
- Instructor overview, training benefits and contact information
- GitHub Pages compatible (no build process)

## Publish
1. Create a **public** repository named `LearnInfra.github.io` in the `LearnInfra` GitHub organization.
2. Upload `index.html` and `README.md` to the repository root on the default `main` branch.
3. Under **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`.
4. The site should appear at `https://learninfra.github.io/` after GitHub Pages deployment.

## Content notes
Course summaries are paraphrased from publicly available LearnInfra pages and link back to the original detailed syllabi. Fees, batch dates, availability, instructor details and certification statements should be reviewed by the LearnInfra team before official publication. This is a new independent design, not a copy of the existing site's proprietary layout or images.
